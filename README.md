# Lighthouse Key

A web application that serves as an assistive planner tool for runs in the game WORLD OF HORROR. Mark down your game settings and Lighthouse symbols, and be shown a to-do list of end game requirements as well as reminders about special character, backstory, and old god effects.

## About

I got tired of making temporary notes and other work-around methods to jot down what symbols were on the lighthouse door, so this is primarily a replacement for doing that. I included character, backstory, and old god notes as a bonus as they are explicity settings you can choose for a run but not all of the impacts are either stated in-game or aren't visible during the run itself.

## Future

I'm currently missing some detailed information for the features of newer characters, which I intend to update either when I have everything unlocked and verified myself, or when the community wiki is updated with this information.

Creating this was spurred by the 1.2 update to WORLD OF HORROR, and as the game could receive further future updates this app may also be updated at that time.
